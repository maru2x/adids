## 概要

このドキュメントでは、`adids` をローカルで動かすために必要なソフトウェアの実行環境をセットアップする手順について説明する。
このセットアップを終えると、次のコマンドを実行できる状態になる。

- `make bootstrap`
- `make test`
- `make docs-check`
- `make pcap-to-log`
- `make log-to-csv`

ちなみに `make run` を実行するには、学習と評価に使用するデータセットの準備が事前に必要。

## 最短のセットアップ手順

`adids` をローカルで動かすために必要なソフトウェアの実行環境をセットアップするためのコマンドとして、 `make bootstrap` が利用できる。ただし、Pythonのバージョンを`3.11.x` にしておく必要がある。

```bash
python --version
```

を実行し、Pythonのバージョンを確認する。
`3.11.x` になっているなら`make bootstrap` は次を自動で行う。

- `.venv` の作成
- `requirements.txt` による依存パッケージのインストール

これにより、pipでインストールできるソフトウェアは基本的にすべて実行可能な状態になる。
ちなみにPython3.11が必要な理由は、 `tensorflow==2.20.0` を含む依存関係の都合で、`Python 3.14` などでは `make bootstrap` が失敗することがあるから。


逆に、pipで入らないソフトウェア（=Zeek）は個別にインストールする必要がある（後述）。
Zeekの入れ方は[公式ドキュメント](https://github.com/zeek/zeek/wiki/Binary-Packages)を参考にインストールすべし。ちなみに自分のZeekのバージョンは `8.0.5`。

## Python 3.11 を用意する方法

sudo権限を実行できる環境では、以下の要領で3.11をインストールできる

```bash
sudo apt update
sudo apt install python3.11 python3.11-venv
python3.11 --version
```
しかし、sudo権限を実行できない環境の場合、 `pyenv` を利用すると指定したPythonのバージョンをインストールできる。

`pyenv` のインストール方法、`pyenv` による Python 3.11 のインストール方法は 
[公式ドキュメント](https://github.com/pyenv/pyenv)を参照。


## 初回確認

セットアップ直後は、まず次が通ることを確認する。

```bash
make test
make docs-check
```

目安:

- `make test`: `src/` の構文チェックと `tests/unit` が通る
- `make docs-check`: docs 関連の最低限の整合が通る

Zeek の実行環境まで確認したい場合は、必要に応じて `make test-e2e` を使う。
ただし、`zeek` コマンドが入っていない環境では skip する。
