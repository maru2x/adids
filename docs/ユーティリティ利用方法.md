## 概要

`src/util/` 配下には、本プロジェクトに使用する補助スクリプトが保存されている。
補助スクリプトは、その用途ごとに以下のようにディレクトリを分けている。

- `FeatureExtract/`: PCAP や Zeek ログから特徴量 CSV を作る
- `DataModified/`: 既存 CSV を加工して別データセットを作る

各ディレクトリは、そのディレクトリ専用の `settings.json` を持つ運用を基本にする。

実験用の leaf CSV ディレクトリを作る全体手順は [実験用データセットの作りかた.md](./実験用データセットの作りかた.md) を参照。

## 抽出済みのCSVファイルを加工するスクリプト群 `DataModified/`

`DataModified/` は、抽出済み CSV に対して何らかの加工を行いたい場合に使用するスクリプトを集めている。

実行時は `src/util/DataModified/settings.json` を編集してから、対象スクリプトを直接実行する。
例：

```bash
python3 src/util/DataModified/two_csv_combine.py
```

### 2つのCSVファイルを結合する `two_csv_combine.py`

`two_csv_combine.py` は、2つの CSV ディレクトリを `daytime` 列の時系列順で結合し、結果を一定件数ごとに分割して出力する。

設定項目:

- `INPUT_DIR_A`
  - 1つ目の入力ディレクトリ
  - 典型的には良性側の leaf CSV ディレクトリを入れる
  - 例: `data/csv/zeek/conn/2201AusEast`
- `INPUT_DIR_B`
  - 2つ目の入力ディレクトリ
  - 典型的には悪性側の leaf CSV ディレクトリを入れる
  - 例: `data/csv/zeek/conn/2201Lab04`
- `OUTPUT_DIR`
  - 結合結果の出力先ディレクトリ
  - `make run` に渡すなら、ここも CSV ファイルだけが並ぶ leaf ディレクトリにする
- `CHUNK_SIZE`
  - 1つの出力 CSV に入れる最大行数
  - 既定値は `3000`

前提:

- 入力 CSV には `daytime` 列があること
- 入力ディレクトリには結合対象の CSV 群が入っていること

結合後は、必要に応じて `src/main/settings.json` の `DATASETS_DIR_PATH` に `OUTPUT_DIR` を設定して `make run` へ渡す。

挙動：

`INPUT_DIR_A` で指定された CSV ファイル群と `INPUT_DIR_B` で指定された CSV ファイル群が、`daytime` の値に基づいて昇順に結合される。
`CHUNK_SIZE` で指定した行数ごとに異なる CSV ファイルとして書き出され、 `OUTPUT_DIR` に出力される。
`INPUT_DIR_A` もしくは `INPUT_DIR_B` に対する編集が行われない。
`OUTPUT_DIR` は空ディレクトリにしておく必要があり、入力 2 系統の CSV ヘッダは一致している必要がある。
各入力ディレクトリには、少なくともどこかの CSV に1行以上のデータが必要である。

### CSVファイルの時間を上書きする `csv_daytime_override.py`

`src/util/DataModified/csv_daytime_override.py` は、1つのCSVディレクトリのdaytimeを、設定した日時に基づいて一斉にずらす。

設定項目：

- `INPUT_DIR`
  - 入力ディレクトリ
- `OUTPUT_DIR`
  - 出力ディレクトリ
- `BASELINE`
  - 基準となる日時

前提:

- 入力 CSV には `daytime` 列があること
- 入力ディレクトリには結合対象の CSV 群が入っていること

挙動：

`INPUT_DIR`で指定された CSV ファイル群の一番最初の時刻が `BASELINE` で指定された日時になり、そのほかの時刻も平行にずらされる。
ずらされた結果の CSV ファイルは `OUTPUT_DIR` に出力され、`INPUT_DIR` に存在する CSV ファイルには編集が行われない
出力ファイル名は、ずらした後の各 CSV の先頭 `daytime` が分かるように付け直される。


## 可視化スクリプト群 `Visualize/`

`Visualize/` は、抽出済み CSV や runtime 結果をグラフ化して確認したいときに使う。

現在の推奨導線は `src/util/Visualize/graph/` 配下で、入力として

```text
data/csv/zeek/conn/2201AusEast
```

のような **CSV ファイルだけが並ぶ leaf ディレクトリ** を受ける。

### データセット全体の特徴量を概観する `feature_dataset_overview.py`

Zeek `conn` leaf CSV ディレクトリ全体を集計し、以下を出力する。

- 総行数、ファイル数、時刻範囲
- feature ごとの欠損率、平均、標準偏差などの summary CSV
- `daytime` の時間バケットごとの flow 数グラフ
- `label` 分布グラフ
- 数値 feature のヒストグラム

実行例:

```bash
python3 src/util/Visualize/graph/feature_dataset_overview.py data/csv/zeek/conn/2201AusEast
```

必要なら出力先や対象 feature を指定できる。

```bash
python3 src/util/Visualize/graph/feature_dataset_overview.py \
  data/csv/zeek/conn/2201AusEast \
  --output-dir exp/2201AusEast_overview \
  --features duration orig_bytes resp_bytes orig_pkts resp_pkts
```

### スライディングウィンドウで分布差を測る `sliding_window_feature_drift.py`

データセット全体、または指定した参照範囲を基準分布として、スライディングウィンドウごとの feature 分布差を測定する。

出力:

- feature ごとの Wasserstein 距離
- feature ごとの KS statistic
- 平均 drift の時系列 CSV / PNG
- feature ごとの drift グラフ

実行例:

```bash
python3 src/util/Visualize/graph/sliding_window_feature_drift.py \
  data/csv/zeek/conn/2201AusEast \
  --window-hours 4 \
  --step-hours 1
```

参照分布を特定期間に限定したい場合:

```bash
python3 src/util/Visualize/graph/sliding_window_feature_drift.py \
  data/csv/zeek/conn/2201AusEast \
  --reference-start "2022-01-10 00:00:00" \
  --reference-end "2022-01-11 00:00:00" \
  --window-hours 4 \
  --step-hours 1
```

### 旧スクリプトについて

従来の観測用 script は `src/util/Visualize/legacy/` へ退避してある。
過去の研究作業を再現したいときは参照できるが、固定 path や旧スキーマ前提が混ざるので、新規利用ではまず `graph/` 側を使う方が安全である。
