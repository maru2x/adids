## 概要

`src/util/` 配下には、本プロジェクトに使用する補助スクリプトが保存されている。
補助スクリプトは、その用途ごとに以下のようにディレクトリを分けている。

- `FeatureExtract/`: PCAP や Zeek ログから特徴量 CSV を作る
- `DataModified/`: 既存 CSV を加工して別データセットを作る

各ディレクトリは、そのディレクトリ専用の `settings.json` を持つ運用を基本にする。

## `src/util/DataModified/`

`DataModified/` は、抽出済み CSV に対して何らかの加工を行いたい場合に使用するスクリプトを集めている。

実行時は `src/util/DataModified/settings.json` を編集してから、対象スクリプトを直接実行する。

```bash
python3 src/util/DataModified/combiner.py
```

### `Combiner`

`combiner.py` は、2つの CSV ディレクトリを `daytime` 列の時系列順で結合し、結果を一定件数ごとに分割して出力する。

設定項目:

- `INPUT_DIR_A`
  - 1つ目の入力ディレクトリ
  - 典型的には良性側の leaf CSV ディレクトリを入れる
- `INPUT_DIR_B`
  - 2つ目の入力ディレクトリ
  - 典型的には悪性側の leaf CSV ディレクトリを入れる
- `OUTPUT_DIR`
  - 結合結果の出力先ディレクトリ
  - `make run` に渡すなら、ここも CSV ファイルだけが並ぶ leaf ディレクトリにする
- `CHUNK_SIZE`
  - 1つの出力 CSV に入れる最大行数
  - 既定値は `3000`

前提:

- 入力 CSV には `daytime` 列があること
- 入力ディレクトリには結合対象の CSV 群が入っていること

結合後は、必要に応じて `src/main/settings.json` の `DATASETS_DIR_PATH` に `OUTPUT_DIR` を設定して `make run` へ渡す。
